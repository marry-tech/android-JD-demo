
# Android JD clone Demo
An undergraduate course project for the *Android Application Development* module at Qilu Normal University. It is a simple e-commerce demo that simulates core pages and basic interaction logic of a shopping app.

## Tech Stack
- Development language: Java
- UI implementation: XML layout, RecyclerView
- Platform: Android SDK
- Local data storage: SQLite

## Main Features
- Home page with commodity list display and banner area
- Category navigation bar for product classification
- Product detail page with complete information presentation
- Basic shopping cart functions: add items, view list, quantity adjustment

## Note
This is a course practice project focusing on basic Android development, UI implementation and data interaction logic.
